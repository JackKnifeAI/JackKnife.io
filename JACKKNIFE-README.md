## 🚀 SETUP INSTRUCTIONS

### Option 1: Local Viewing
1. Download ALL 8 HTML files
2. Put them in the SAME folder (e.g., `jackknife-website/`)
3. Open `jackknife-site-v2-complete.html` in your browser
4. Click the quantum learning buttons - they'll open in new tabs!

### Option 2: Web Hosting (Recommended)
1. Upload ALL 8 HTML files to your web host
2. Make sure they're in the same directory
3. Set `jackknife-site-v2-complete.html` as your index or rename to `index.html`

## ⚠️ COMMON ISSUES

**Links not working?**
- Make sure ALL files are in the SAME folder
- Don't rename files (links depend on exact filenames)
- Some browsers block local file links - try a local server or upload to hosting

**Running a local server (optional):**
```bash
# Python 3
cd your-website-folder
python -m http.server 8000
# Then open http://localhost:8000
```
